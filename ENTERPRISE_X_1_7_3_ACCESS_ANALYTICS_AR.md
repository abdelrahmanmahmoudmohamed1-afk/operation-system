# Enterprise X 1.7.3

- Admin can change any system profile between Admin/User and Active/Inactive.
- Safety rule prevents demoting/deactivating the last active Admin.
- Universal table pagination: 10 / 20 / 30 / 40 / 50 rows across data tables.
- Dashboard page headers and table headers are sticky.
- Reports now add an interactive Power BI-style analysis layer with KPI cards and charts for project value, status mix and top sales.
- Orientation report separates Orientation, Workshop and Visit activity, with activity filtering and independent KPIs.
