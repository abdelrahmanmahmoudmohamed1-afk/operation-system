النسخة الكاملة المجمعة — Operation System

تحتوي على الواجهة الزرقاء وإصلاحات البناء وبدء التشغيل وجميع ملفات الخادم والربط الأصلية.

طريقة التحديث:
1. فك الضغط.
2. انسخ محتويات operation-system-main إلى جذر المستودع الحالي، واختر استبدال الملفات. لا تضع المجلد داخل مجلد آخر بنفس الاسم.
3. يجب أن يكون package.json وvercel.json وindex.html في نفس المستوى.
4. Commit ثم Push origin.
5. مجلد Root Directory في Vercel هو جذر المشروع، وليس public.
6. أمر البناء npm run build ينشئ public تلقائياً. إعدادات Vercel مضمنة في vercel.json.
7. إن كان النشر Staged، استخدم Promote to Production لتحديث operation-system-six.vercel.app.

التحقق المحلي: نجح فحص JavaScript والاستيرادات وتوافق إجراءات API وإنشاء public والتحقق من محتوى index.html. ظهرت شاشة الدخول في اختبار المتصفح المحلي.

حدود التحقق: لم يُختبر تسجيل الدخول الحقيقي أو عمليات Supabase وGoogle Sheets أو نشر هذه الحزمة على حساب Vercel. سبب آخر فشل بناء على حسابك غير معروف لأن سجل الخطأ التفصيلي لم يُرسل.

لا تنسخ مجلد .git من أي أرشيف؛ هذه الحزمة لا تحتويه. حافظ على متغيرات البيئة الحالية في Vercel.
